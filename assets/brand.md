# PickleDB Brand Guidelines

## Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| Primary Green | `#2E7D32` | Headers, highlights |
| Light Green | `#4CAF50` | Success states, positive indicators |
| Dark Green | `#1B5E20` | Footer, dark backgrounds |
| Primary Blue | `#1565C0` | Links, interactive elements |
| Light Blue | `#42A5F5` | Info, secondary highlights |
| Warm Orange | `#EF6C00` | Warnings, cautions |
| Red | `#C62828` | Errors, destructive actions |
| Dark Gray | `#212121` | Text, primary content |
| Medium Gray | `#616161` | Secondary text, metadata |
| Light Gray | `#F5F5F5` | Backgrounds (light mode) |
| Dark Bg | `#1E1E1E` | Backgrounds (dark mode) |

## Logo

The PickleDB logo uses the ASCII art representation shown in `banner.txt`.

## Typography

- **Headers**: Monospace (JetBrains Mono, Fira Code, or system monospace)
- **Body**: System UI font stack
- **Code**: Monospace

## Tagline

> Encrypt everything. Trust nothing.

## Tone

- Professional and technical
- Security-focused
- Concise and direct
- No marketing fluff

## Badge Style

Use flat-square badges with the primary green color scheme.

Example:
```
[![Crates.io](https://img.shields.io/crates/v/pickledb-core?style=flat-square&logo=rust)](https://crates.io/crates/pickledb-core)
```
